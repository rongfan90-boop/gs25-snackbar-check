물건이 오면 바코드를 찍기만 하면 돼요. 다 들어왔는지, 빠진 게 있는지 휴대폰이 알아서 세어 줘요. 👍

1로그인하기

  • 처음이면 처음이에요 (점포 등록) 누르기
  • 우리 점포 이름을 쓰고, 비밀번호 숫자 4~6자리를 정해요
    (확인 칸에 한 번 더!)
  • 다음부터는 점포 이름 + 비밀번호로 로그인
🔒 비밀번호는 꼭 메모해 두세요!

2납품목록 넣기

  • 📋 납품목록 화면에서 납품일이 오늘인지 보기
  • 엑셀에서 바코드 · 상품명 · 수량을 복사해서 큰 칸에 붙여넣기
  • 붙여넣기 반영 누르면 끝!
💡 지난번이랑 같으면 🗂 기록 → 지난 기록 → 납품목록만 다시 쓰기

3바코드 찍기 📷

  1. 📷 입고검수 화면에서 📷 바코드 스캔 누르기 → 카메라 "허용" 누르기
  2. 상품 바코드를 네모 칸 안에 비추면 "삑!" 하고 저절로 체크돼요
  3. 카메라가 안 켜지면 📸 사진으로 찍기를 눌러 바코드 사진을 찍어도 돼요
✅ 초록색이 나오면잘 들어온 상품이에요. 다음 상품을 찍어요!
❌ 빨간색이 나오면"금번 입고 상품이 아닙니다" → 이번 물건이 아니니 따로 두세요
✏️ 개수가 모자라게 왔다면? 목록에서 그 상품을 눌러서 숫자를 고쳐요. 아예 안 왔으면 0 (미입고)

4카톡 보내기

  • 💬 결과·카톡 화면으로 가기
  • 📋 문구 복사하기 누르기
  • 카카오톡 채팅방에 붙여넣기 → 보내기
빠진 상품 이름과 개수가 저절로 정리돼요 ✨

5저장은 알아서! 💾

  • 찍는 동안 자동으로 저장돼요. 따로 안 눌러도 OK
  • 🗂 기록에서 "11월 3주차"처럼 주차별로 지난 기록을 다시 볼 수 있어요
  • 휴대폰을 바꿔도 로그인하면 그대로 있어요

🙋 이럴 땐 이렇게!

카메라가 안 켜져요
→ 📸 사진으로 찍기를 쓰거나, 휴대폰 설정에서 카메라 허용을 켜 주세요.
바코드를 못 읽어요
→ 바코드를 가운데에 크게, 흔들리지 않게 찍어요. 그래도 안 되면 바코드 밑 숫자를 직접 입력해요.
비밀번호를 잊어버렸어요
→ 담당 OFC에게 물어보세요.
예전 화면이 보여요
→ 화면을 아래로 당겨 새로고침 해요.

🚚 하루에 여러 번 배송할 때

🚚 배송분할 → 납품목록 불러오기 → 배송 횟수(예: 2회) 고르기 → 회차마다 % 적기 (예: 60 / 40)

그다음 1회차 검수를 누르면 그 회차 물량만 찍을 수 있어요.

📱 꿀팁: 주소를 홈 화면에 추가하면 앱처럼 바로 열려요!
