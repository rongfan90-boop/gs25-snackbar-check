📦 입고검수 사용법

휴대폰으로 여기 접속! rongfan90-boop.github.io/
gs25-snackbar-check

순서는 ① 납품목록 → ② 점포입고 → ③ 고객사납품 → ④ 카톡. 화면 아래 버튼도 이 순서예요. 👍

0로그인하기

  • 처음이면 처음이에요 (점포 등록)
  • 점포 이름 + 비밀번호 숫자 4~6자리 정하기
  • 다음부터는 로그인만
🔒 비밀번호는 꼭 메모해 두세요!

1납품목록 넣기

  • ①납품목록에서 고객사 · 납품일 확인
  • 엑셀에서 바코드 · 상품명 · 수량 복사 → 큰 칸에 붙여넣기
  • 붙여넣기 반영 누르면 끝!

2점포 입고검수 🏪 물건이 점포에 들어왔을 때

  1. ②점포입고 → 📷 바코드 스캔 → 카메라 "허용"
  2. 바코드를 네모 칸에 비추면 "삑!" → 숫자판에 들어온 개수 누르고 확인 → 다음 상품
✅ 숫자판이 뜨면이번 상품이 맞아요. 개수 넣고 확인!
❌ 빨간색이 나오면이번 상품이 아니에요. 따로 두세요

3고객사 납품검수 🚚 고객사에 가져갈 때

  1. ③고객사납품 → 처음 한 번만 납품 횟수(예: 2회)와 회차별 % 정하기 → ✅ 1회차 납품검수 시작
  2. 가져갈 상품을 찍고 개수 넣기 (점포 입고 때와 똑같아요)
  3. 다음 납품 때는 위의 2회차 버튼을 누르고 찍기
🔁 1회차에 못 가져간 수량은 2회차에 자동으로 더해져요 (목록에 "이월 +50"처럼 표시)

4카톡 보내기

  • ④결과·카톡에서 보낼 결과 고르기
    🏪 점포 입고 또는 🚚 1회차 (고객사용)
  • 📋 문구 복사하기 → 카카오톡에 붙여넣기

5저장은 알아서! 💾

  • 찍는 동안 자동 저장돼요
  • 🗂 기록에서 "11월 3주차"처럼 주차별로 다시 보기
  • 로그인하면 다른 폰에서도 이어서 할 수 있어요 (한 번에 한 폰만!)

🙋 이럴 땐 이렇게!

카메라가 안 켜져요
→ 📸 사진으로 찍기를 쓰거나, 휴대폰 설정에서 카메라를 허용해 주세요.
바코드를 못 읽어요
→ 가운데에 크게, 흔들리지 않게. 안 되면 바코드 밑 숫자를 직접 입력해요.
카메라 허용을 자꾸 물어봐요
→ 스캔 화면을 끝날 때까지 닫지 마세요. (아이폰: 설정 → Safari → 카메라 → 허용)

🙋 더 궁금해요

개수를 잘못 넣었어요
→ 목록에서 그 상품을 눌러서 숫자를 고쳐요.
비밀번호를 잊어버렸어요
→ 담당 OFC에게 물어보세요.
